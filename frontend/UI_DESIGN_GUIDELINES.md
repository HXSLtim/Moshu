# 墨枢 工作区设计规范(v2·CODEX 风格化)

本文描述当前实现和后续交互约束。产品方向是 **VS Code 式连续创作工作区**：章节、正文、设定和 AI 对话在同一界面协作，作者无需反复打开续写弹窗。代码入口见 [workspace/page.tsx](app/workspace/page.tsx)。

**v2(2026-10-03,用户定调)【初稿——候用户看稿确认后为正式规格;确认前批次视觉仍按 v1 执行】**:视觉整体转 **CODEX 风**——终端工具感:深色优先、克制排版、等宽气质、紧凑、线框化、去 MUI 默认感,与桌面壳(Tauri)同窗。**换皮不换骨**:语义层规格(状态色语义表/密度两档/卡片两级/三件套原语/作者语言纪律/候选与安全条款)全部延续 v1;视觉参数(色板/圆角/阴影/字体/组件外观)全套更新。v1→v2 差异集中在「视觉规范」与「迁移注记」两节。

## 布局

| 区域 | 当前行为 |
|---|---|
| 左侧活动栏 | 章节目录、设定与伏笔、创作对话入口 |
| 章节资源管理器 | 可收起，章节分页加载；打开章节时按需读取正文 |
| 中央标签区 | 章节标签与设定标签；当前页面保留最近最多 10 个章节标签 |
| 正文编辑区 | 标题与纯文本正文、自动保存、撤销和冲突处理 |
| 右侧 AI 区 | 常驻「对话」且为**唯一动作入口**：能力(编排/高级续写/选区改写/剧情走向/资料检索)由 Agent 按意图自主调用工具,内联折叠块展示调用过程;输入框旁为审核模式选择器(每次确认/自动采纳/全部采纳)与排队输入 |
| 底部状态栏 | 保存状态、章节与字数信息 |

桌面从 MUI `md`（900 px）断点使用左右分区；较窄屏幕使用正文与 AI 上下分区，章节目录通过抽屉打开。当前不支持拖动分栏宽度、多编辑器并排、刷新恢复全部标签或命令面板，不能把这些 VS Code 能力写成已实现。

## 连续对话

- 对话归属于小说，切章或切到设定不会清空历史。对话头部展示当前章节，说明下一条消息的上下文。
- 输入区固定在底部，消息区独立滚动。意图包括讨论、续写、高级续写、改写、大纲、角色、检查和起草下一章。
- 已送达的问题和回复保存在服务端；刷新后恢复最近记录，可加载更早记录。未送达输入仅在当前页面保留，不承诺关闭页面后恢复。
- 正文类任务产生服务端候选。采纳前检查作者、作品/章节生命周期、版本和正文哈希，确认后由服务器同事务保存新版本与采纳记录。
- 切换章节后仍可查看旧回复，但不得把旧章候选无提示地写进新章。
- 停止、失败、加载历史和正文冲突有明确状态；不得以空白回复或成功提示掩盖失败。
- 查看完整历史与模型实际使用的上下文是两回事；记忆按预算和来源范围召回，当前没有会话分支。

## 工具与正文保护

动作型能力(高级续写、选区改写、剧情走向、资料检索、编排)是 **Agent 的工具**:由模型按作者意图自主调用,调用过程以内联折叠块(动词+对象+状态)展示,可展开摘要。稿件类工具产出候选提案并按本书审核模式(每次确认/自动采纳/全部采纳三档)处理;选区改写依赖作者随消息上传的当前选区。处理中输入框进入排队模式(Enter 入队,上一轮完成自动发送)，发送键变停止。管理型内容(章节记忆、文风样本库、角色统计)在「设定」页维护。工具路由由模型判断,选错时按诚实失败处理,不伪装成功。

选区改写先显示原文与可编辑候选，作者确认后精确替换。正文、章节或选区变化时阻止旧结果覆盖。保存冲突展示双方版本，并提供采纳服务端、覆盖和另存新章；不能要求作者直接刷新来解决未保存草稿。

「起草下一章」与 `auto-chapter` 都先返回候选，作者确认才创建章节。**新章创建类候选(create)不受审核档位自动采纳,任何档位(auto/none 均含)都需作者显式确认后才建章;改稿类(append/replace)的三档语义不变。**高级续写追加当前章，不把生成稿通过普通建章 API 绕过采纳审计。

自动采纳后的界面跟手:落点=当前章且编辑器无未保存稿→编辑器自动加载新稿;有未保存稿→本地稿优先不动+双稿提示,保存时走既有冲突三选;落点≠当前章→仅章节列表/统计刷新。提示词根用「自动采纳」。

「设定」页维护计划/实际大纲、独立实体、状态区间与候选审阅。允许同名实体，使用说明和稳定标识区分；计划与已发生剧情、当前状态与历史清晰分开。来源过期须重新核对，确认/拒绝/撤销使用幂等命令。

「章节记忆」可查看不可变原文版本；先选择恢复，再明确确认，服务器建立新版本。未保存稿禁止直接恢复，在途再编辑保留新稿。排队和运行中的简介提供取消入口。

草稿绑定服务端核验作者和作品/章节生命周期；跨作者或删建后不自动恢复。旧格式与过时草稿保留导出候选。登录身份变化时撤销编辑与工具入口，旧请求不更新新工作区。

## 视觉规范(v2·CODEX 风)

**深色优先**:默认主题深色(CODEX 系冷灰);浅色保留纸墨纸感作日间写作档。用户主题偏好 localStorage 记忆,已存偏好的老用户不迁移、新默认为深色。壳窗口 chrome(标题栏/菜单)与页面同调:深色+1px 细边框。主题事实源是 [theme.ts](theme/theme.ts)。

| MUI token | 深色(默认) | 浅色(日间) |
|---|---|---|
| `primary.main` | `#4EC9A1` | `#006C52` |
| `background.default` | `#0A0A0A` | `#F9F7F2` |
| `background.paper` | `#121212` | `#FFFFFF` |
| `background.subtle` | `#1A1A1A` | `#F3F0EA` |
| `text.primary` | `#E8E8E8` | `#1D1C1A` |
| `text.secondary` | `#9B9B9B` | `#5F5F5F` |
| `divider` | `#2A2A2A` | `#C7C2B9` |

状态色 token 已随批1 落值,v2 微调深色列适配冷底(语义映射不变):

| token | 深色 | 浅色 |
|---|---|---|

| `error.main` | `#E5655E` | `#B3403A` |

### 形体语言(v2 全新)

- **圆角:全局 2 px**(v1 的 8 px 作废);标签、Chip、按钮、弹窗、输入框全部方角化。v1「工作区标签局部直角」条款并入全局。
- **全站零 elevation**:页面与浮层都不投影。浮层(Dialog/Menu/Popover)=实底 `background.paper`+1px `divider` 边框,靠层级与边框立 depth,不靠阴影。
- **1px 线框是主结构语言**:`divider` 色细线分界区块与容器。
- 不要悬浮抬升动画;hover 反馈用背景档(`background.subtle`)不用阴影。

### 字体系统(v2 全新)

- **UI 中文**:系统栈(-apple-system/PingFang SC/Microsoft YaHei);零在线字体(壳内自包含)。
- **数字/拉丁/代码感元素用 mono**:`ui-monospace/SF Mono/JetBrains Mono/Consolas` 栈——落在字数统计、章号、版本号、时间戳、用量行、章节号标签、状态栏;非 mono 场景 `font-variant-numeric: tabular-nums` 兜底。
- **正文阅读区禁 mono**:小说正文保持中文阅读体 16 px/行高 1.75(对话流中的稿件阅读同此)——等宽是工具气质,不是阅读体。
- 字档沿用 v1 定档方向(body2/subtitle2/caption 显式定档);UI 层排版更克制:行高收紧、减少装饰性字重。

### 密度分档(骨不动)

| 档位 | 适用 | 间距 | 字号 | 列表 |
|---|---|---|---|---|
| 工作密度 | workspace 编辑器、对话输入控件、侧栏 | 4-8 px | 13-14 px | dense |
| 管理密度 | dashboard、详情页、设定账本、人物档案 | 16-24 px | 15-16 px | 标准 |

例外:对话流中的稿件阅读保持正文排版(16 px/1.75),不因位于紧凑区而缩小。

### 卡片层级语言(骨不动,皮锐化)

两级封顶。一级卡(1px 边框,零影)是页面区块容器;内嵌卡(零影,subtle 背景或 1px 边框圆角块)是一级卡内的条目组。禁止三级嵌套。

### 状态色语义表(骨不动)

色 + 文字双通道,错误不能只靠颜色。核心三分:**错误 ≠ 拒绝 ≠ 失效**。

| 语义 | 色阶 | 形态 | 账本/提案/保存域映射 |
|---|---|---|---|
| 进行中/pending/生成中 | 中性灰 | 实心 + 进行指示 | 待处理提案、保存中 |
| 成功/有效/已采纳 | success 绿 | 实心 | 账本「有效」、提案「已采纳」、保存「已保存」 |
| 正向属性/已发生/既成 | success 绿 | 描边 | 账本「已发生」、对话「已写入」 |
| 已拒绝/正常裁决 | default 灰 | 描边 | 提案「已拒绝」(**禁用红**——拒绝不是错误) |
| 已失效/stale/来源未确认 | warning 琥珀 | 描边 | 账本「已失效」、AutoSaver「未保存/离线」 |
| 失败/错误/冲突 | error 红 | 实心 | 保存失败、生成失败、版本冲突 |
| 计划中/未发生 | default 灰 | 描边 | 账本「计划中」 |
| 无数据/missing | 灰 | 文字空态 | 「还没有 X」+引导,禁占位假数据 |

实心/描边分工规则:实心表达「当下状态」,描边表达「属性标签/历史既成」。Chip 尺寸两档:small(元信息标签:章节号、来源)与 medium(状态章、可点操作);方角。

### 组件约定

- **Button variant**(规则骨不动):每个视图一颗主操作 contained;次操作 outlined;行内轻操作 text;破坏性操作 error 色+确认对话框。保存类主操作一律 contained。视觉:方角 2px。
- **空态**:统一「还没有 X」+一句引导(怎么做就有);禁「暂无 X」裸句与新式混用。
- **加载态**:CircularProgress 16-24+文案;禁 12 px 微旋。
- **标点**:省略号全角「…」、冒号全角「：」;同面板不混。
- **数字**:千位分隔统一 `toLocaleString()`;统计数字以 mono 呈现。
- **图标**:一图一义;EditIcon/MenuBookIcon 双义修复随批3。
- **弹窗尺寸映射**:sm=确认/单字段,md=表单,lg=版本对比或多栏复杂内容;弹窗=实底+1px 边框,零影。
- **DialogActions**:取消在左 text,主操作在右 contained;破坏性主操作用 error contained。
- **字档定档**:theme.typography 显式定档实际主力 body2/subtitle2/caption;fontWeight 700/800 字面量收进 typography 定档,组件侧 sx 清零。
- **spacing**:不强推全局统一刻度;间距节奏在原语内部固定。

### 共享原语(骨不动,皮参数随 theme 全局变)

依据 frontend 样式盘点(.Codex/frontend-style-primitives-inventory.md)。三件套(SectionHeader/EmptyState/StatusChip)已随角色管理分支落地,统一批次收编平移;收编只挪位置不改行为。

| 原语 | 职责 | 收编批次 |
|---|---|---|
| SectionHeader | 区块头(subtitle2/700+可选 Divider+右侧动作槽) | 批 3 |
| EmptyState | 空态/单行状态说明(title+hint+action 槽,severity 默认 info) | 批 4 |
| StatusChip | 状态章(tone 映射状态色语义表;刻度收进原语) | 批 1(已落) |
| InlineCollapsible | 无影内联折叠块 | 批 2/5 |
| BorderCallout | 并入卡片 emphasized 变体,不单设原语 | 批 2 |

约束:StatusChip 的 tone 枚举只取状态色语义表色阶,不私设色;**审核模式选择器(批1 归一)**:对话栏与项目信息面板统一同一 ToggleButtonGroup(exclusive/small)形态,词汇固定「每次确认/自动采纳/全部采纳」(值 confirm/auto/none 不动),激活态 primary 描边+浅底、禁实心——它不是状态章,不进 StatusChip tone 表。**分类/属性章一律中性阶描边**(如人物重要程度主力/次要/龙套):彩色通道只承载状态语义,分类与层级差异用文字、字重、排序表达。tone 表为封闭枚举:`neutral` 是唯一的非状态档,其余 tone 全部映射状态色语义表;新增彩色档须先过语义表,属性标签不得借用状态色档。属性标签不用裸 Chip——统一走 StatusChip。

## 键盘与可访问性

- 图标按钮提供中文可访问名称,标签暴露选中状态;错误不能只靠颜色表达。
- 对话记录使用日志区域,生成和加载提供文本状态;避免重复播报整段历史。
- 正文撤销与对话/设定输入框的原生撤销互不干扰。
- 中文输入法组合期间不发送消息或触发工作台快捷键。
- 快捷键清单与组件职责见 [前端开发指南](../docs/guide/前端开发指南.md),AI 请求协议见 [AI_STREAMING_GUIDE.md](AI_STREAMING_GUIDE.md)。

## 交互验收

1. 编辑正文后切章，确认保存或冲突保护生效。
2. 发起对话，切换工具、设定和章节，确认历史不清空。
3. 刷新页面恢复服务端历史，并加载更早记录。
4. 正文改变后采纳旧候选，确认不会覆盖新稿。
5. 验证停止后的迟到回复、断网、较窄屏幕、深浅主题与中文输入法。
6. (v2)换皮后全页深色走查:零阴影、方角、mono 数字对齐、正文阅读区非 mono、状态色深浅两档对比度达标。
