## 记忆实时性补强（2026-09-13）

ContextPack 现在在 `scope.memory_head_version` 冻结结构化记忆快照。作者确认、替换、撤销状态或来源失效会递增 `StoryMemoryHead.version`；模型返回后、候选落库前再次校验该版本。版本变化时旧上下文候选被拒绝，避免作者刚确认的新状态仍被旧上下文覆盖。`context_builder` 和候选保存回归覆盖该竞争窗口。

本次后端全量为 **547 passed、2 skipped**（`.Codex/memory-realtime-truth-final.log`）；新增实时性和真实性定向用例后 65 项核心账本/上下文测试通过。该栅栏保护的是结构化记忆快照，不会中止已经发给模型的计算；上游已产生的费用仍按执行记录保留。

真实性补强：公开 StoryFact 创建现在写入当前 `novel_lifecycle_id`；Alembic c0f4a6b8d123 和无历史旧库兼容路径会按 `novel_id → novels.rag_lifecycle_id` 回填旧事实。生成上下文遇到仍未绑定生命周期的遗留事实会排除并报告 `legacy_unscoped_fact`，避免把整数主键当作归属证明。

## 架构复审结论

数据库仍是作者正文、版本、正式账本和对话的唯一真源；Chroma、简介、状态投影和评测输出都带来源并可重建。AI 生成统一经过任务枚举、上下文预算、完成契约和候选采纳，取消、超时、版本或生命周期变化时不会写入正文。

本轮重点复核了跨租户与生命周期、删除后整数 ID 复用、事务回滚、后台租约、旧结果覆盖、来源哈希、前端切章/切账号迟到响应、正式事实与结构化状态的独立预算。发现的问题已修复并纳入对应回归；关闭明细见关闭清单。

## 保留边界

1. G18 尚未达到文学质量验收：固定样例的 12 例对照、作者盲评、采纳率和成本分析需在模型可用时执行；不能用结构/出处通过代替作者评价。
2. G19 的本机模型已可用，但只完成长章结构/出处实测；已有真实 Embedding、PostgreSQL 和 DSH 证据只证明这些链路，不证明所有模型配置或生产并发。
3. L2/L3 当前按有界扫描和预算召回，manifest 会报告省略；跨全书语义检索、自动状态晋升、Neo4j/Redis/Qdrant 仍不是核心依赖。
4. 真实作者数据库尚未迁移，运行 `QUICKSTART.md` 中的备份、预检和 Alembic 步骤前不得把隔离证据当作生产升级。
5. 工作区是本地 Alpha：每本小说一条主对话，逐句采纳、EPUB 和完全离线冷启动仍未实现。
