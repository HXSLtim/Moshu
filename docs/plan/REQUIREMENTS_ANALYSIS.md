# Nai 当前需求与迭代顺序

更新于 2026-09-13，以当前工作区代码为准，未提交不代表已发布。定位是作者主导的长篇写作工具，核心流程为编辑、交流、审阅候选、保存。

## 已明确的产品方向

用户要求 VS Code 式布局，正文、设定和 AI 对话在同一工作区持续使用；切换章节后保留交流，避免每次续写重新调出弹窗。深浅「纸墨」配色保留，正文目前采用纯文本编辑。

## 当前状态

| 需求 | 状态 | 剩余边界 |
|---|---|---|
| 章节保存、版本冲突、离线草稿 | 已实现 | 持久版本历史可只读查看；无网络冷启动读取与一键历史恢复未实现 |
| VS Code 式工作区、常驻对话 | 已实现基础版 | 拖动分栏、恢复全部标签、多编辑器并排未实现 |
| 小说级对话历史 | 已实现 | HTTP 完整回复；最近 20 轮/8000 字符历史预算；无长期摘要或分支 |
| AI 候选审阅 | 已实现 | 对话、续写、改写和 auto-chapter 均先生成候选；逐句采纳仍未实现 |
| 世界观、事实与事件账本 | 已实现 | L2 大纲、L3 人物/物品状态已接通；地点模型仍未纳入 |
| 伏笔 | 事件字段可记录 | 未实现完整的埋设、推进、回收状态与引用关系 |
| 多阶段续写、RAG、一致性与审核 | 已有独立工具 | 常驻对话仍是单模型入口，复杂工具需作者显式选择 |
| Alembic、SQLite WAL / busy_timeout | 已实现 | PostgreSQL 迁移已在隔离库验证；生产并发仍需专项演练 |
| 深浅主题、统一字数统计、快捷键 | 已实现 | 持续做可访问性与窄屏体验验收 |
| 整本 TXT 导出 | 已实现 | EPUB、超大作品流式导出未实现 |
| 真实模型质量评测 | 部分完成 | 两个长章真实结构/出处已运行；12 例对照与作者盲评待执行 |
| 可恢复投影 / AI 任务 | 已实现当前范围 | 简介与 RAG 投影均有持久任务、租约恢复、取消/重试；生产多进程仍需演练 |

小说/章节/角色附属记录级联、历史事实筛选、计划事件过滤、取消竞争、草稿备份与缺参考检查状态已修复；不自动清理历史遗留孤儿。高级续写故事日、客户端来源身份与一致性参考接线已完成，详见 [架构评审](../design/底层架构评审.md) 与 [实施蓝图](../design/架构实施蓝图.md)。

## 下一阶段优先级

| 顺序 | 目标 | 验收结果 |
|---|---|---|
| 1 | 统一 AI 应用服务与模型配置 | 对话和高级续写复用调用入口、上下文预算和错误语义，路由不互相导入模型对象 |
| 2 | 原文版本、来源引用、可恢复提取任务与 L1 简介 | 原文有可追溯版本；任务可重试；改稿后旧简介退出召回 |
| 3 | L2 结构化大纲、L3 高频设定与主角物品 | 计划与实际分开，按章读取人物/物品状态，不提前注入未来剧情 |
| 4 | 对话内调用续写/改写工具，统一候选 | 一次交流能调用工具并记录结果；采纳与章节版本关联，拒绝过期与重复应用 |
| 5 | 真实模型评测与作品演示 | 固定样例覆盖续写、人设、伏笔和改写，记录模型、提示词版本、延迟与结果 |

步骤 1 起同步建立小规模质量基线，避免重构后生成退化；不等最后一步才首次验证真实模型。M0、M1、L2/L3 当前范围和有界共享召回已实现并经本地验证；真实质量验收待在模型可用时执行，具体边界及迁移验收见 [底层架构评审](../design/底层架构评审.md)，四层数据与更新规则见 [记忆分层设计](../design/记忆分层设计.md)。

暂不优先引入微服务、Redis、Neo4j 或更多 Agent。是否迁移 PostgreSQL/Qdrant 由实际并发和检索规模决定，新增基础设施不能替代调用和数据边界的整理。
