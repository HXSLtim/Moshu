# 前后端协议

本文定义前后端之间的契约与变更流程。端点明细见 [API对接文档](API对接文档.md);本文只约定机制。

## 单一事实源与生成链

```
backend response_model(Pydantic)
  → backend/export_openapi.py 生成 frontend/openapi.json(入库)
  → frontend `npm run codegen`(orval)生成 lib/api/generated/(入库,不手改)
```

- 任何 response_model 改动必须同 PR 完成:导出 openapi.json + 重跑 codegen + 提交生成物
- 校验:`cd backend && .venv/bin/python export_openapi.py --check`(带 8 个代理变量清理)漂移退出码非 0
- `lib/api/mutator.ts` 是唯一传输层:token 头、`ApiError`、错误信息提取、Abort 语义;生成客户端与旧 `apiRequest` 同源
- 未声明 response_model 的端点在生成物中为宽松类型,按消费需要逐个补模型

## 约定

- **错误**:非 2xx 抛 `ApiError(message, status)`;message 提取 `detail`(字符串或校验数组)
- **幂等**:`request_id`(UUID)同域唯一,重试复用同一 ID
- **乐观锁**:`expected_version`/生命周期 ID 不符返回 409,客户端进入冲突流程
- **持久任务**:AI 生成统一走 `POST /generation/jobs`(202 入队,轮询恢复);`kind` 为受控枚举,当前含 `chat/generate/continue/rewrite/auto_chapter/outline/character/init/plot_options/orchestrate`
- **SSE**(不在 OpenAPI 范畴):事件字典为 `metadata`/`chunk`/`tool`/`agent`/`ahead`/`done`/`error`;客户端 `lib/sse.ts` 为唯一实现,事件语义变更须同步本文与 [AI 流式指南](../../frontend/AI_STREAMING_GUIDE.md)

## 破坏性变更流程

1. 后端改 schema → 导出 openapi.json → codegen → typecheck 暴露所有受影响调用方
2. 同 PR 修复前端;不做向后兼容垫片(项目规范),API 文档与本文同步
3. 验证:后端 `run_tests.sh --mode all`;前端 `codegen && lint && typecheck && test`
